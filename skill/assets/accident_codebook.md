# 高校实验室事故案例编码手册（第二编码人用）

**任务**：对事故案例逐条编码。只依据事实描述，不参考任何既有编码结果。编码值从下表选填。

## 事故类型
火灾 / 爆炸 / 毒害 / 生物感染 / 腐蚀 / 其他

## 危险因素
危险化学品 / 仪器设备 / 线路 / 生物因素 / 其他或未知

## 事故环节
危化品使用 / 危化品储存 / 仪器设备使用 / 实验室管理 / 废弃物处理 / 动物购买饲养 / 其他

## 原因一级
A-操作不规范 / B-环境不良 / C-管理缺陷 / D-设备材料失效 / E-未知

## 原因二级
违规操作 / 操作不慎 / 废弃物处理不当 / 设备老化故障 / 线路老化短路 / 化学品储存不规范 / 管理意外 / 动物未检疫 / 反应失控 / 未知

## 原因分层（2-4 模型映射）
- 个体层面（不安全动作）：违规操作、操作不慎、废弃物处理不当
- 组织层面（管理体系/安全文化缺欠）：化学品储存不规范、管理意外、培训缺位
- 物因层面（不安全物态）：设备老化故障、线路老化短路、反应失控
- 交叉层：动物未检疫
- 未知原因不纳入分层

## 判定原则
- 优先看直接原因；信息不足就选"未知"，不要推测；
- 多因素并存时选主导因素，促成因素记入备注；
- 每条编码可在备注写一句依据（可选）。
